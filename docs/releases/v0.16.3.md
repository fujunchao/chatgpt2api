# v0.16.3

修复内置 OAuth 网页登录的 Free 账号有图片额度，却不显示 `gpt-image-2.5` 的问题。

## 修复内容

- 将内置浏览器登录产生的 `oauth_login` 来源纳入 Web 图片账号判断，与 `web`、`password` 一同支持。
- `/v1/models` 和图片请求选号使用同一处来源判断，同时修复模型不显示和直接请求误报 `no available web image quota`。
- 保留原始账号来源记录，无需把 `oauth_login` 手动改为 `web`。
- Codex 来源及 Plus / Team / Pro 条件不变；本次没有向 Free 账号开放 Codex 图片工具。
- 保留既有 Web 请求、HTTP/1.1、严格断流恢复与未知用量标记，不更换图片引擎或扩大重试。

`gpt-image-2.5` 仍是本项目的 **Web 自动兼容入口**，具体图片引擎由官网选择，不能据此确认或指定 Flare / Sunburst。

## 验证

- 182 项后端离线回归、4 项前端逻辑测试通过。
- 独立 TypeScript 类型检查和 Next.js 生产构建通过。
- 新回归覆盖内置 OAuth 登录完成 → 账号入库 → 模型目录 → Web 图片调用，而不仅是手工构造 `source_type=web` 的账号。
- 离线回归不等于真实上游出图或具体图片引擎身份验证。

## Docker 升级

镜像支持 `linux/amd64`、`linux/arm64`：

```bash
docker pull ghcr.io/fujunchao/chatgpt2api:0.16.3
```

使用本版本已更新的 Compose 文件：

```bash
docker compose pull app
docker compose up -d --no-deps app
```

保留自己的 `config.json` 和 `data/`，不要叠加旧版本源码覆盖挂载。升级后确认面板版本为 `0.16.3`，重新获取模型列表，选择 `gpt-image-2.5`（Web 自动）。已有账号仍需满足正常状态及图片额度要求。

详细用法见 [Free Web 接入说明](https://github.com/fujunchao/chatgpt2api/blob/v0.16.3/docs/free-web-image-integration.zh-CN.md)。测试凭证、生产数据和诊断缓存均不包含在发布中。
