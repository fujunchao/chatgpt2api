# v0.16.1

基于上游 v1.6.0，整合生产图片传输补丁并增加 GPT Image 2.5 的 Codex 请求链路。

## 新增与修复

- 支持 `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`，以及明确的 `codex-*` 别名和套餐前缀；保留原 2.0 默认值。
- 2.5 模型分别传入 Codex `image_generation` 工具的 `model`，不是仅修改显示名称。
- Web 图片 SSE 使用 HTTP/1.1；提交后断流优先使用已有会话 ID，缺失时严格核对本次消息 ID，避免取错会话和重复出图。
- 保留连接释放与出图后隐藏会话功能，异步清理使用独立连接。
- 补齐 Responses 工具模型、多参考图及 Chat 图片尺寸/质量透传；新增 `xhigh`、`max` 质量档位。
- 2.5 优先使用上游真实用量，缺失时标记 `unavailable`；修复多图错误状态丢失及错误体截断处理。

## 验证

- 167 项后端离线测试、3 项前端逻辑测试通过。
- 独立 TypeScript 检查及 Next.js 生产构建通过。
- 尚未使用真实账号验证上游出图；2.5 需要符合条件的 Codex 来源账号及上游权限。

## Docker

GitHub Actions 构建并发布 `linux/amd64`、`linux/arm64` 镜像：

```bash
docker pull ghcr.io/fujunchao/chatgpt2api:0.16.1
```

常规部署使用仓库的 `docker-compose.yml`；需要本地源码构建时使用 `docker-compose.image25.yml`。

这次涉及新增模块和前端，不能只沿用旧生产包的两个源码覆盖挂载。保留自己的 `config.json` 和 `data/`，按[整合说明](https://github.com/fujunchao/chatgpt2api/blob/v0.16.1/docs/image25-production-integration.zh-CN.md)部署。

本地生产压缩包、运行数据和凭据不包含在本次发布中。
