# v0.16.4

通过现有网页账号接入 Image 2.6 Sunburst / Flare，支持文生图、参考图编辑、Chat/Responses 兼容及后台任务。准备与提交均发送具体型号；短名 `gpt-image-2.6` 固定请求 Sunburst。

## 新增与修复

- 三个 2.6 入口统一匹配网页、密码及 OAuth 网页来源，模型目录和界面显示网页路由。
- 网页质量及尺寸作为提示；未接通的原生格式、GIF/SVG、复杂度等控制明确报错，包括 Responses 顶层和工具参数。
- 多图请求共用最多 3 次型号权限试用，保留真实权限错误；已提交或状态未知的请求不会因此重复生成。
- 静态 PNG/JPEG/WebP 保留原始字节、正确后缀及媒体类型，下载和继续编辑一致；缺少真实用量时显示不可用。
- 修复任务“继续等待”的旧参数错误，使用原账号摘要和原会话恢复；服务重启后保留恢复字段，续轮询使用同样的格式及用量处理。
- 修复提交时连接重置、接收或发送失败可能重投的问题，按本次消息 ID 恢复；准备阶段及明确的 TLS 握手错误保留安全重试。
- 版本说明解析兼容 Windows 换行符，更新提示正确显示版本号与日期。

## 验证

- 213 项后端离线回归、7 项前端逻辑测试、独立 TypeScript 类型检查及前端生产构建通过。
- Free/OAuth 网页账号实际验证 Sunburst 与 Flare 的生成和参考图编辑，以及短名映射；五项均返回 PNG，每项仅提交一次。
- 两轴代码审查通过，原审查发现的问题均已修复并加入回归。

真实验收只覆盖此次 Free/OAuth 账号；付费账号未实测。网页模型请求和会话元数据匹配所选变体，独立底层引擎身份仍未认证。完整证据见 [网页验收记录](https://github.com/fujunchao/chatgpt2api/blob/v0.16.4/docs/research/image26-web-acceptance-2026-11-12.zh-CN.md)。

## Docker 升级

镜像支持 `linux/amd64`、`linux/arm64`：

```bash
docker pull ghcr.io/fujunchao/chatgpt2api:0.16.4
docker compose pull app
docker compose up -d --no-deps app
```

保留现有 `config.json` 和 `data/`。升级后确认面板版本 `0.16.4`，重新获取模型目录，选择 `gpt-image-2.6-sunburst` 或 `gpt-image-2.6-flare`。旧版本超时任务缺少原账号摘要时会明确报恢复失败。

详细接口、能力边界与上游依据见 [网页接入说明](https://github.com/fujunchao/chatgpt2api/blob/v0.16.4/docs/image26-web-integration.zh-CN.md)。
