# v0.17.0

网页 Image 2.6 新增实验 GIF 生成与静态参考图动画化。三个网页 2.6 名称均可使用，短名继续请求 Sunburst；原有 PNG 默认参数保持兼容。

## 功能

- 在生成、编辑、Chat、Responses 和后台任务中接受 `output_format="gif"`。可选帧数 2–16、间隔 20–2000 毫秒仅作为提示，不透传为网页原生参数。
- 成功必须是真实、至少两帧且可完整解码的 GIF。过滤伴随 PNG 预览；静态、单帧、损坏或 SVG 结果明确失败，不自动重新生成。
- 保存原始字节、`.gif` 后缀、`image/gif` 和动画元信息，支持本地/WebDAV 保存、原动画播放下载、历史复用与跨重启原会话恢复。
- 网页新增“GIF（实验）”，管理员可调整实验开关和 GIF 等待预算。动画参考图、动画遮罩及后续帧损坏的 GIF 输入明确拒绝，请使用静态输入动画化。

## 验证

Free/OAuth 网页账号的 Flare、Sunburst 文生动画和静态参考图动画化四项均返回 HTTP 200 / 九帧 GIF，每项只提交一次；所有帧可解码且存在九个不同解码帧。原图、哈希和精确耗时见 [真实验收](https://github.com/fujunchao/chatgpt2api/blob/v0.17.0/docs/research/image26-gif-acceptance-2026-11-12.zh-CN.md)。

232 项后端隔离回归、11 项前端测试、独立 TypeScript 类型检查和前端生产构建通过。浏览器核对原动画播放、下载哈希、刷新恢复、历史复用及关闭开关后的拒绝提示；规范与需求复查无剩余发现。具体账号权限、实际动作、尺寸和帧数仍以上游为准。

## 升级

镜像支持 `linux/amd64`、`linux/arm64`：

```bash
docker pull ghcr.io/fujunchao/chatgpt2api:0.17.0
docker compose pull app
docker compose up -d --no-deps app
```

保留现有 `config.json` 与 `data/`，升级后面板版本应为 `0.17.0`。两份 Compose 文件均已固定到该版本。

GIF 默认开启，等待预算默认 300 秒。用法、配置和实验限制见 [GIF 接入说明](https://github.com/fujunchao/chatgpt2api/blob/v0.17.0/docs/image26-gif-guide.zh-CN.md)。本次发布包含新版本与镜像，服务器验收使用隔离源码；部署中的旧容器需要按上述命令升级后使用。
