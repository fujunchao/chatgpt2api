# v0.16.5

修复 CVA 调用网页 Image 2.6 时报“尚不支持原生参数 output_format”的兼容问题。

CVA 在 JSON 生成和 multipart 编辑中都固定发送 `output_format="png"`，v0.16.4 的预检规则将其直接拒绝。本版本接受这个客户端默认值并继续使用原网页管线，CVA 无需修改。

## 范围与验证

- PNG 默认值不透传为网页原生控制；其它未接通的格式选择和原生参数仍明确报错。
- 新增生成与编辑 HTTP 回归，确认正确型号、PNG 图片结果和实际网页请求中没有该字段。
- 215 项后端离线回归通过；规范与需求复查均为 0 项问题。
- 服务器隔离源码完成 CVA 形状的真实网页生成与参考图编辑：客户端携带 PNG 默认参数，两项均返回 200 / PNG，每项只提交一次，实际网页请求均未携带该原生字段。
- 前端生产构建通过。

## 升级

镜像支持 `linux/amd64`、`linux/arm64`：

```bash
docker pull ghcr.io/fujunchao/chatgpt2api:0.16.5
docker compose pull app
docker compose up -d --no-deps app
```

保留现有 `config.json` 和 `data/`。升级后面板版本应为 `0.16.5`，CVA 可继续发送原有 PNG 默认参数。

详细用法见 [网页 Image 2.6 接入说明](https://github.com/fujunchao/chatgpt2api/blob/v0.16.5/docs/image26-web-integration.zh-CN.md)。
