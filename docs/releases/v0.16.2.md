# v0.16.2

新增 Free 网页账号可用的 `gpt-image-2.5` Web 自动图片入口，保留 v0.16.1 的 Codex 路由和生产补丁。

## 新增与修复

- 裸 `gpt-image-2.5` 复用原 `gpt-image-2` 的 Web 图片请求，支持有图片额度的 Free / 付费网页登录账号；旧默认值不变。
- 新 Web 入口只选择 `web` / `password` 来源账号，远端账号刷新后再次核验来源；不会误选 Codex 账号，也不会在 Web 配额耗尽时静默切换通道。
- 模型目录和图片工作台明确标注 **Web 自动**：图片引擎由官网选择，具体版本未知，不能指定 Flare / Sunburst。
- 新入口没有上游实际用量时省略 `usage`、返回 `usage_source="unavailable"`，覆盖流式结果和后台任务，不套用旧引擎的估算公式。
- 既有 `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`、`codex-*` 和套餐前缀继续使用付费 Codex 路由，不改变其账号条件。
- 保留 Web 图片 HTTP/1.1、严格消息 ID 恢复和已提交请求不盲目重投的生产补丁；未重写现有登录或重试流程。

## 验证

- 181 项后端离线回归、4 项前端逻辑测试通过。
- 独立 TypeScript 类型检查和 Next.js 生产构建通过。
- 回归覆盖新旧 Web 请求一致性、Free 选号、混合账号来源隔离、生成/多参考图编辑、Chat/Responses、流式及后台任务。
- 尚未使用真实账号独立验证新入口的上游出图或图片引擎身份；名称是本项目的兼容路由，不代表已确认具体 2.5 变体。

## Docker

GitHub Actions 构建并发布 `linux/amd64`、`linux/arm64` 镜像：

```bash
docker pull ghcr.io/fujunchao/chatgpt2api:0.16.2
```

仓库 `docker-compose.yml` 和源码构建用的 `docker-compose.image25.yml` 已同步到 `0.16.2`。使用更新后的 Compose 文件升级已有部署：

```bash
docker compose pull app
docker compose up -d --no-deps app
```

保留自己的 `config.json` 和 `data/`，不要叠加旧生产包的两个源码覆盖挂载。新入口的调用示例、账号条件及用量说明见 [Free Web 接入说明](https://github.com/fujunchao/chatgpt2api/blob/v0.16.2/docs/free-web-image-integration.zh-CN.md)。

本地生产压缩包、研究缓存、运行数据与凭据不包含在本次发布中。
